# ClassRelay v2.10.0

ClassRelay는 Google Form 신청자와 은행 입금 CSV를 대조한 뒤, 입금이 확인된 신청자에게 강의별 안내 메일이나 녹화본 메일을 Gmail로 발송하고 CS 히스토리를 로컬에 보존하는 local-first 웹앱입니다.

## v2.10.0 운영 로직 정리

- 강의 생성 필수값은 강의명과 가격입니다. 녹화본 URL은 선택사항입니다.
- 녹화본 URL이 없어도 신청/Form 동기화/입금 확인/일반 안내메일 발송이 가능합니다.
- 메일 템플릿이 `{{녹화본URL}}` 변수를 실제로 사용할 때만 해당 강의에 녹화본 URL이 필요합니다.
- Google Form 질문 매핑에서 `결제금액`을 제거합니다. 신청 금액은 사용자가 입력하는 값이 아니라 신청 당시 강의 가격을 자동 저장합니다.
- 기존 신청 건의 금액은 이후 강의 가격이 변경되어도 유지합니다. 이 값이 은행 CSV 입금액과 매칭됩니다.
- 메일/로그 문구는 녹화본 전용 표현보다 일반 `메일 발송` 중심으로 정리합니다.

## v2.9.0 가이드 전면 개편

이번 버전은 애플리케이션 운영 로직을 변경하지 않고 `/guide`를 완전 초보자용 튜토리얼로 전면 재작성한 문서/UX 버전입니다.

- Google Cloud를 처음 쓰는 사용자를 위한 용어 설명 추가
- `프로젝트 → Forms/Gmail API → Branding → Audience → Data Access → Clients`를 실제 클릭 경로로 세분화
- Test user 등록과 `403 access_denied` 해결 절차 상세화
- 실제 사용 scope 3개를 Data Access에서 추가하는 방법 안내
- Authorized JavaScript origins와 Client ID 생성 과정을 초보자 기준으로 상세화
- ClassRelay에 Client ID를 저장하는 위치와 완료 상태 안내
- 강의 생성, 추천 Google Form 질문 구성, 긴 `/edit` URL 복사 방법 상세화
- Form 질문 매핑, 전체/개별 동기화, CSV 열 매핑, 자동매칭 상태 설명 보강
- Course-first Gmail 발송과 발송로그 확인을 단계별로 재작성
- CS/재발송/백업 절차 상세화
- `테스트 강의 → Form → 테스트 CSV → 본인 Gmail 발송` 전체 실습 챕터 추가
- Google 공식 문서 링크를 최신 메뉴 구조 기준으로 재검수

## 핵심 운영 원칙

### 강의 중심 Form 연결

- 새 강의를 만들고 해당 강의의 새 Google Form 편집 URL을 연결합니다.
- 대시보드의 `폼 추가`는 새 Form 연결, `전체 폼 동기화`는 활성 강의 Form 전체 갱신입니다.
- 강의 히스토리의 `이 강의 폼 동기화`는 현재 강의 Form만 갱신합니다.
- 재동기화해도 기존 입금·발송·CS 히스토리는 초기화하지 않습니다.

### Course-first Sending

메일 발송은 항상 **강의 → 발송 가능 대상 → 선택 → 최종 확인 → 발송** 순서로 진행합니다.

- 한 번의 발송 작업에는 하나의 강의만 포함됩니다.
- 강의 히스토리에서는 현재 강의를 그대로 유지한 채 발송 대상으로 진입합니다.
- 발송 직전 강의명, 인원, 템플릿, 제목과 필요한 변수 값을 다시 확인합니다. `{{녹화본URL}}`을 쓰는 템플릿만 녹화본 URL을 요구합니다.

## 저장 및 개인정보

신청자, 입금, 템플릿, 발송로그는 중앙 DB가 아니라 사용자의 브라우저 IndexedDB에 저장합니다. Google Access Token은 영구 저장하지 않습니다.

## 검증

`npm test`와 `npm run check`로 핵심 로직과 정적 회귀 검사를 실행할 수 있습니다.

## v2.9.1 가이드 타이포그래피 개선
`/guide`의 초보자 설명을 문서 surface에 맞게 재조정했습니다. 핵심 본문과 행동 안내는 16px, 보조 설명은 15px, 라벨/출처 같은 메타는 12~13px로 제한했습니다. 핵심 지시문은 ink 계열을 사용하고, 완료 기준·주의·팁·용어 카드의 여백도 함께 키웠습니다. 모바일에서는 문서 전체 가로 overflow를 제거하고, 넓은 표만 해당 표 컨테이너 안에서 가로 스크롤하도록 유지합니다. 앱의 신청·입금·발송 기능은 변경하지 않았습니다.


## v2.9.2 Google 설정 따라하기 보강
실제 Google Auth Platform 화면에서 초보 사용자가 막힌 지점을 기준으로 `/guide`를 다시 보강합니다. 개인 Gmail 사용자의 `외부 → 다음`, 대상 화면의 Test user 추가 위치, Data Access의 `범위 직접 추가`, OAuth Client 생성 완료 팝업의 `확인`, 테스트 앱 경고의 `계속`, Forms 권한 두 항목 선택과 하단 `계속`까지 버튼 단위로 설명합니다. scope 값은 링크가 아니라 복사해서 붙여넣는 일반 code 값으로 표시합니다. 앱 운영 로직과 IndexedDB 스키마는 변경하지 않습니다.
