# ClassRelay v2.7.0

Local-first 강의 신청·입금 확인·녹화본 메일 발송 관리자 도구입니다.

## v2.7.0 핵심
- **강의 중심 Google Form 연결**: 새 Form은 특정 강의에 직접 연결합니다.
- 대시보드에 `폼 추가`와 `전체 폼 동기화`를 함께 제공합니다.
- 강의 히스토리에서는 `이 강의 폼 동기화`로 해당 강의만 갱신합니다.
- 새 강의를 저장하면 `Google Form도 지금 연결할까요?` 흐름으로 바로 이어집니다.
- Google Drive API로 사용자의 Form 전체 목록을 조회하지 않습니다. Form 편집 URL을 한 번 연결한 뒤 ClassRelay에서 관리합니다.
- 과거 연결 이력이 있는 같은 Form은 새 강의에 재사용하지 못하게 하여 신청 히스토리 충돌을 방지합니다.
- 메일 템플릿의 `사용 강의`를 리스트형 선택 UI로 바꿨습니다.
- 최근 발송 내역은 좁은 사이드 카드가 아니라 전체 폭 테이블로 표시합니다.
- `/guide`의 Google Form, Gmail, YouTube, 동기화 설명을 실제 동작 기준으로 다시 검수했습니다.

## 데이터 원칙
- 물리 IndexedDB는 하나지만 신청·입금·발송·CS 기록은 `courseId`로 강의별 분리됩니다.
- Form 동기화는 response ID 기준 증분 병합이며 기존 입금/발송/CS 이력을 초기화하지 않습니다.
- 새 강의에는 새 Form을 연결하고 과거 강의의 Form/히스토리는 보존합니다.
- 사용자 데이터와 CSV는 중앙 DB로 업로드하지 않습니다.

## 주요 기능
- Google Form 강의별 연결 및 전체/개별 동기화
- 은행 CSV 누적 가져오기 및 보수적 자동 입금매칭
- 강의별 누적 히스토리와 CS 메모
- Gmail 개별 발송·재발송·발송 당시 내용 보존
- 여러 메일 템플릿 + 기본/강의별 전용 템플릿
- 로컬 백업/복원
