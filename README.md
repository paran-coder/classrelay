# ClassRelay v2.6.2

Local-first 강의 신청·입금 확인·녹화본 메일 발송 관리자 도구입니다.

## v2.6.2 핵심
- `+ 템플릿 추가`는 **빈 템플릿 신규 작성** 전용입니다.
- 신규 작성 화면에서 `템플릿 이름 / 사용 강의 / 제목 / 본문`을 한 번에 입력합니다.
- 기존 내용을 기반으로 새 템플릿을 만들 때는 `복제`를 사용합니다.
- 이미 다른 전용 템플릿이 연결된 강의를 신규 템플릿에 연결하면 기존 연결 교체 확인을 거칩니다.
- 생성 직후 새 템플릿이 자동 선택됩니다.
- 템플릿은 별도 object store 없이 기존 IndexedDB `settings`에 저장합니다.

## 주요 기능
- Google Form 신청 동기화
- 은행 CSV 누적 가져오기 및 보수적 자동 입금매칭
- 강의별 누적 히스토리와 CS 메모
- Gmail 개별 발송·재발송·발송 snapshot
- 여러 메일 템플릿 + 기본/강의별 전용 템플릿
- 로컬 백업/복원

테스트: `npm test`
문법 검사: `npm run check`
